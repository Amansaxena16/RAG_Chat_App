# NovaTech Product Overview

## NovaBoard

NovaBoard is a Kanban-style project management tool. Teams organize work into "Spaces," which contain multiple boards, each with customizable columns (e.g., Backlog, In Progress, Review, Done). Key features include:

- **Automation rules**: e.g., "when a card enters Review, assign it to the team's designated reviewer."
- **Dependencies**: cards can block or be blocked by other cards, and NovaBoard warns you if you try to move a blocked card to Done.
- **Workload view**: shows how many active cards are assigned to each team member, to help spot overload.
- **Integrations**: two-way sync with GitHub issues and pull requests, and native NovaChat notifications for card updates.

NovaBoard is the most widely adopted NovaTech product, used by roughly 80% of paying customer organizations.

## NovaChat

NovaChat is a team messaging application with channels, direct messages, and built-in video huddles (up to 50 participants). Distinctive features include:

- **Threaded huddles**: a video call can be started directly from a message thread, and the recording (if enabled) is attached back to that thread.
- **Smart notifications**: NovaChat learns which channels a user replies to often and reduces notification volume for channels the user mostly skims.
- **NovaBoard cards from chat**: any message can be converted into a NovaBoard card with a right-click, preserving the message thread as the card's initial comments.

## NovaSync

NovaSync is a file synchronization and document collaboration service, similar in spirit to a shared drive but with real-time co-editing for documents, spreadsheets, and whiteboards. Key features:

- **Version history**: every save creates a restorable version, kept for 90 days on the Growth plan and indefinitely on the Enterprise plan.
- **Smart folders**: folders that automatically collect files based on rules (e.g., "all files shared with the Marketing space in the last 30 days").
- **Offline mode**: desktop and mobile apps cache recently accessed files for offline editing, syncing automatically when connectivity returns.

## Unified Search

All three products share a single search index. Searching from within NovaChat, for example, will also surface matching NovaBoard cards and NovaSync files, provided the searching user has access to them. This unified search is only available when a customer organization has at least two of the three products active.

## Platform Availability

NovaBoard, NovaChat, and NovaSync are available as:
- Web applications (all major browsers)
- Desktop apps for macOS and Windows
- Mobile apps for iOS and Android (NovaChat and NovaSync only — NovaBoard mobile is view-only as of the current release)
